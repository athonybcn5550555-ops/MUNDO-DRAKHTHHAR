# Tienda Etsy: DrakhtharSoftware — Kit de lanzamiento

Documentación de trabajo para lanzar y operar la tienda de Etsy
**DrakhtharSoftware** (software offline, compra única, sin suscripciones).

| Archivo | Para qué sirve |
|---|---|
| `01-plan-lanzamiento.md` | Diagnóstico, posicionamiento, decisiones pendientes, fases y KPIs. |
| `02-ficha-producto.md` | Ficha que hay que rellenar por cada herramienta antes de redactar su listing. |
| `03-plantilla-listing.md` | Estructura SEO de un listing de Etsy (título, tags, descripción, imágenes, vídeo). |
| `04-politicas-y-textos-tienda.md` | Borradores en inglés de "About", políticas y FAQ para productos digitales. |
| `05-checklist-publicacion.md` | Lista de comprobación antes de publicar cada listing y para la tienda. |
| `06-precios-y-comisiones.md` | Cómo se calcula el neto de una venta y bandas de precio recomendadas. |
| `calculadora_precio.py` | Script que calcula el neto por venta con las comisiones de Etsy (España). |

Orden de trabajo recomendado: leer `01`, tomar las decisiones pendientes que
se listan allí, rellenar una `02` por producto y solo entonces redactar
listings con `03`.

Las cifras de comisiones de Etsy cambian con el tiempo. Las que aparecen aquí
están marcadas como "verificar" y deben contrastarse en el Panel de vendedor
antes de fijar precios definitivos.
