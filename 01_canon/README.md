# Canon — biblia del mundo

Esta carpeta es la **única fuente de verdad** del universo. Solo se considera canon lo que tiene el estado `Canon` en su ficha.

| Carpeta | Contenido |
|---|---|
| `personajes/` | Una ficha por personaje (usa `_plantilla_personaje.md`). |
| `lugares/` | Regiones, ciudades, lugares importantes. |
| `facciones/` | Razas, reinos, órdenes, gremios. |
| `historia/` | Cronología y acontecimientos. |
| `sistemas/` | Magia, religión, tecnología, economía, idiomas. |
| `glosario.md` | Términos propios del mundo y cómo se escriben. |
