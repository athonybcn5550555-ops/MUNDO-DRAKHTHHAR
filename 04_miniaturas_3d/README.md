# Miniaturas 3D

## Flujo de trabajo
1. **Diseño:** hoja de modelo aprobada en `03_arte/personajes/`.
2. **Escultura digital:** modelo base.
3. **Preparación:** división en piezas, encajes, peana.
4. **Optimización:** según tecnología (FDM o resina), ver la ficha.
5. **Prueba de impresión:** resultado y ajustes anotados en la ficha.
6. **Aprobación** → pasa a `06_comercial/etsy/`.

## Carpetas
- `fichas/`: una ficha por miniatura (usa `_plantilla_ficha_miniatura.md`).
- `modelos/`: archivos 3D. **Ver decisión D-003** antes de subir archivos STL grandes.
