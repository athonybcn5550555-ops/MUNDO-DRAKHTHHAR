# Comercial

| Carpeta | Contenido |
|---|---|
| `kdp/` | Metadatos de cada libro: título, subtítulo, descripción, palabras clave, categorías, precio, ISBN. |
| `etsy/` | Fichas de producto: título, descripción, etiquetas, precio, fotos, licencia. |
| `marketing/` | Plan de lanzamiento, calendario de contenidos, redes, newsletter. |

Todo el texto público debe usar la grafía oficial (D-001) y ser coherente con `05_marca/`.
