# MUNDO DRAKHTHHAR — Proyecto JL

Repositorio central del Proyecto JL: el universo de fantasía épica, la novela, el arte, las miniaturas 3D, la marca y su comercialización.

> ⚠️ **Grafía oficial pendiente.** El repositorio se llama *DRAKHTHHAR*, pero en otros materiales aparece *Drakhthar*. Ver [`00_gestion/DECISIONES.md`](00_gestion/DECISIONES.md). No uses ninguna de las dos en material público hasta que se decida.

## Mapa del repositorio

| Carpeta | Para qué sirve |
|---|---|
| [`00_gestion/`](00_gestion/) | Decisiones, pendientes y convenciones. **Empieza aquí.** |
| [`01_canon/`](01_canon/) | Biblia del mundo. **Única fuente de verdad** del universo. |
| [`02_novela/`](02_novela/) | Manuscrito, borradores y notas de edición. |
| [`03_arte/`](03_arte/) | Referencias, concept art, diseño de personajes y portadas. |
| [`04_miniaturas_3d/`](04_miniaturas_3d/) | Fichas y modelos para impresión FDM/resina. |
| [`05_marca/`](05_marca/) | Identidad visual y verbal. |
| [`06_comercial/`](06_comercial/) | Amazon KDP, Etsy y marketing. |

## Regla de oro

Todo lo que se crea en `02` a `06` **se basa en `01_canon/`**. Si una idea nueva contradice el canon, primero se decide (y se anota en `00_gestion/DECISIONES.md`), después se actualiza el canon y solo entonces se usa en el resto de carpetas.
